HIG help

These commands look up Apple's Human Interface Guidelines and original web or native design notes. Reload MCP servers in Cursor if a command is missing.

Commands

  • /hig/helpShow this help.
  • /hig/topicRead one guideline, such as buttons or sheets, without designing. Optional platform.
  • /hig/webDesign a website or web app. Example task: design a card.
  • /hig/iosDesign an iPhone interface.
  • /hig/ipadosDesign an iPad interface.
  • /hig/macosDesign a Mac interface.
  • /hig/watchosDesign an Apple Watch interface.
  • /hig/tvosDesign an Apple TV interface.
  • /hig/visionosDesign an Apple Vision Pro interface.
  • /hig/convertRewrite an existing design so it follows the guidelines. Fill in the description and platform.
  • /hig/auditCheck an existing design and list the fixes. Fill in the description and platform.

How to design

Put what you want designed in the task field. The command already sets the platform. Example: /hig/web with task “design a card”.

For /hig/topic, name the guideline, such as buttons or sheets. Add a platform to drop other platforms' notes.

For /hig/convert and /hig/audit, paste the current screens, layout, controls, and copy, and name the platform.

The agent then calls guide_interface, get_design_reference, and get_topic, and keeps the Apple source URL in the answer. It can also call search_hig to find a page, and list_topics to browse a section.
